# Fog of Pawn – RimWorld 1.6

Not all pawns are what they seem. Skills, passions, and traits can be hidden or faked when colonists join, creating uncertainty and emergent stories.

## Core Mechanics

**Four Deception Tiers:**
- **Truthful** – All attributes shown accurately (default ~65%)
- **Slightly Deceived** – Minor skill/passion alterations
- **Imposter** – Low-skill pawns faking competence, drop disguise kits when exposed
- **Sleeper** – Elite pawns hiding their power with a unique multi-phase storyline

**Reveals happen through:**
- Time, mood, and social interactions
- Skill use (XP accumulation)
- Mental breaks
- Prisoner interrogation
- Manual accusation system

**Imposters:** When exposed, they drop disguise kits (reduces wealth), suffer permanent social penalties, and trigger colony mood buffs if removed.

**Sleepers:** Trigger a 1-2 season incident chain with suspicious activity letters, culminating in a dramatic reveal where you choose to keep, capture, or exile them.

## Features

- Skill/passion/trait masking with gradual reveals
- Work tab shows masked skill levels
- Flat 5% failure penalty when using faked skills (configurable)
- Prisoner interrogation speeds up reveals
- Fully configurable spawn rates and reveal mechanics
- Dev mode gizmos for testing
